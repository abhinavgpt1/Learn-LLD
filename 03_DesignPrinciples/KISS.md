KISS (Keep It Simple, Stupid) principle is a fundamental design philosophy in software development that emphasizes simplicity and clarity in code and system design.
The core idea behind KISS is that systems should be designed in the simplest way possible, avoiding unnecessary complexity and over-engineering.
By adhering to the KISS principle, developers can create more maintainable, understandable, and efficient codebases, 
making it easier for teams to collaborate and for future developers to work with the code.

For example, if you only need to check whether a number is even, use num % 2 == 0 instead of creating a complex utility class or algorithm.
The goal is to improve readability and maintainability.
