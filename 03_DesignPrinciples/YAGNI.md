YAGNI, which stands for "You Aren't Gonna Need It," is a software development principle that encourages developers
to avoid adding functionality or features to a system until they are actually needed. 
The core idea behind YAGNI is to prevent over-engineering and unnecessary complexity in codebases 
by focusing on delivering only what is required at the moment.

Example: While developing an online shopping application, you need to support UPI payments. 
You implement UPI payment functionality but avoid building cryptocurrency payments, international currency conversion, 
and loyalty-point integration when there is no current requirement for them.
