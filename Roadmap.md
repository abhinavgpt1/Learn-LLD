### LLD Prerequisites:
1. One OOPS language hands-on with OOPS concepts
2. Collections framework or alike library knowledge
3. Data structures theoretical knowledge
4. Basic algos knowledge on these DS
5. UML - atleast do class, sequence and use case diagrams
    Checkout course: https://www.coursera.org/learn/object-oriented-design
6. Design Principles - DRY, YAGNI, KISS, SOLID
    Checkout articles here 
    - https://github.com/ashishps1/awesome-low-level-design
    - https://algomaster.io/learn/lld/dry
7. Design Patterns - not all but remember these 
    - singleton
    - factory
    - abstract factory
    - builder
    - adapter
    - decorator
    - facade
    - composite
    - observer
    - command
    - strategy
    - state
    - template
    
    Checkout:
    * my github codes - https://github.com/abhinavgpt1/Design-Patterns
    * article - https://refactoring.guru/design-patterns
    * book - Clean Code by Robert C. Martin
    * course - https://www.coursera.org/learn/design-patterns
    * book - Head First Design Patterns

> Go ahead with practicing LLDs now.
